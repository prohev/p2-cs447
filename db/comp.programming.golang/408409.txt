<!-- SC_OFF --><div class="md"><p>Hello!</p> <p>I&#39;m writing a library to simplify and optimize operations with files (everything is a file): <a href="https://github.com/cnaize/pipe">https://github.com/cnaize/pipe</a></p> <p>Example:</p> <pre><code>func main() { // create a pipeline pipeline := pipes.Line( // set execution timeout common.Timeout(time.Second), // open two example files localfs.OpenFiles(&quot;testdata/test_0.txt&quot;, &quot;testdata/test_1.txt&quot;), // calculate and compare hash for each file hash.SumSha256(&quot;kEvuni09HxM1ox-0nIj7_Ug1Adw0oIU62ukuh49oi5c=&quot;, &quot;CeE_WA_xKsx2Dj_sRvowaCeDfQOPviSpyjaZdxuCT4Y=&quot;), // zip the files archive.ZipFiles(), // calculate hash for the zip archive hash.SumSha256(&quot;&quot;), // create a temporary directory localfs.MakeDirAll(&quot;testdata/tmp&quot;, os.ModePerm), // create a new file localfs.CreateFiles(&quot;testdata/tmp/test.zip&quot;), // flow the files through the pipes and keep metadata state.Consume(), ) // run the pipeline res, _ := pipeline.Run(context.Background(), nil) // iterate over result files and print metadata for file := range res.Files { fmt.Printf(&quot;--&gt; Result file:\n\tName: %s\n\tSize: %d\n\tHash: %s\n&quot;, file.Name, file.Size, file.Hash) } } </code></pre> <p>Output:</p> <pre><code>--&gt; Result file: Name: testdata/tmp/test.zip Size: 1047 Hash: Yg3OOaBD-miLs7lDIBVAeZMZIXYfy2N25f8-b-1kWOc= </code></pre> <p>Please, take a look and give any feedback, thanks!</p> </div><!-- SC_ON --> &#32; submitted by &#32; <a href="https://www.reddit.com/user/cnaize42"> /u/cnaize42 </a> <br/> <span><a href="https://www.reddit.com/r/golang/comments/1jayjxz/pipe_operations_library/">[link]</a></span> &#32; <span><a href="https://www.reddit.com/r/golang/comments/1jayjxz/pipe_operations_library/">[comments]</a></span>
