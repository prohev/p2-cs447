You also store the data locally in Influxdb and can take static backups.</p> <p><strong>Comparison</strong> </p> <p>Fitbit discontinued their web app, now you are forced to use their &quot;simplified&quot; app. This can be a good replacement with better visualization.</p> <p>Here is the <a href="https://github.com/arpanghosh8453/public-fitbit-projects">complete code on GitHub </a>( free to run on your own machine locally if you want )</p> <p>There is a <a href="https://hub.docker.com/r/thisisarpanghosh/fitbit-fetch-data/tags">pre-built docker container </a>for self hosting enthusiasts.</p> <p>Please star it if you like the project!
