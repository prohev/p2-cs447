<!-- SC_OFF --><div class="md"><p><strong>What My Project Does</strong></p> <p><code>create-intro-cards</code> is a production-ready Python package that converts a Pandas DataFrame of individuals&#39; names, photos, and custom attributes into a PDF of “intro cards” that describe each individual—all with a single function call. Each intro card displays a person&#39;s name, a photo, and a series of attributes based on custom columns in the dataset. (<a href="https://github.com/robertfmath/create-intro-cards">link to GitHub</a>, which includes photos and pip installation instructions)</p> <p>The input is a Pandas DataFrame, where rows represent individuals and columns their attributes. Columns containing individuals&#39; first names, last names, and paths to photos are required, but the content (and number) of other columns can be freely customized. You can also customize many different stylistic elements of the cards themselves, from font sizes and text placement to photo boundaries and more.</p> <p>The generated PDF contains all individuals&#39; intro cards, arranged four per page. The entire process typically takes only a few minutes or less—and it&#39;s completed automated!</p> <p><strong>Target Audience</strong></p> <p>The PDF generated by the package is a great way for <strong>groups</strong> and <strong>teams</strong> to get to know each other. Essentially, it&#39;s a simple way to transform a dataset of individuals&#39; attributes—collected from sources such as surveys—into a fun, easily shareable visual summary. <em>Some</em> baseline proficiency in Python is required (creating a Pandas DataFrame, importing a package) but I tried to make the external API as democratized and simple as possible to increase its reach and availability.</p> <p>It is entirely intended for production. I put a lot of effort into making it as polished as possible! There&#39;s a robust test suite, (very) detailed documentation, a CI pipeline, and even a logo that I made from scratch.</p> <p><strong>Comparison</strong></p> <p>What drove me to make this was simply the <em>lack</em> of alternatives. I had wanted to make an intro-card PDF like this for a group of 120 people at my company, but I couldn&#39;t find an analogous package (or service in general), and creating the cards manually would&#39;ve taken many, many hours. So I really just wanted to fill this gap in the &quot;code space,&quot; insofar as it existed. I genuinely hope other people and teams can get some use out of it—it really is a fun way to get to know people!</p> <p>Thanks for reading!</p> </div><!-- SC_ON --> &#32; submitted by &#32; <a href="https://www.reddit.com/user/For-Projects"> /u/For-Projects </a> <br/> <span><a href="https://www.reddit.com/r/Python/comments/1jawsk6/createintrocards_convert_a_dataset_of_peoples/">[link]</a></span> &#32; <span><a href="https://www.reddit.com/r/Python/comments/1jawsk6/createintrocards_convert_a_dataset_of_peoples/">[comments]</a></span>
