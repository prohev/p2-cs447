<!-- SC_OFF --><div class="md"><h1>What my project does</h1> <p>Rusty Graph is a high-performance graph database library with Python bindings written in Rust. It transforms SQL data into knowledge graphs, making it easy to discover relationships and patterns hidden in relational databases.</p> <h1>Target Audience</h1> <ul> <li>Data scientists working with complex relational datasets</li> <li>Developers building applications that need to traverse relationships</li> <li>Anyone who&#39;s found SQL joins and subqueries limiting when trying to extract insights from connected data</li> </ul> <h1>Implementation</h1> <p>The library bridges the gap between tabular data and graph-based analysis:</p> <pre><code># Transform SQL data into a knowledge graph with minimal code graph = rusty_graph.KnowledgeGraph() graph.add_nodes(data=users_df, node_type=&#39;User&#39;, unique_id_field=&#39;user_id&#39;) graph.add_connections( data=purchases_df, connection_type=&#39;PURCHASED&#39;, source_type=&#39;User&#39;, source_id_field=&#39;user_id&#39;, target_type=&#39;Product&#39;, target_id_field=&#39;product_id&#39;, ) # Calculate insights directly on the graph user_spending = graph.type_filter(&#39;User&#39;).traverse(&#39;PURCHASED&#39;).calculate( expression=&#39;sum(price * quantity)&#39;, store_as=&#39;total_spent&#39; ) # Extract patterns like &quot;products often purchased together&quot; products_per_user = graph.type_filter(&#39;User&#39;).traverse(&#39;PURCHASED&#39;).children_properties_to_list( property=&#39;title&#39;, store_as=&#39;purchased_products&#39; ) </code></pre> <p>Available on PyPI: <code>pip install rusty-graph</code> </p> <p>GitHub: <a href="https://github.com/kkollsga/rusty-graph">https://github.com/kkollsga/rusty-graph</a></p> <p>This is a project share post.
