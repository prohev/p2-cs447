<!-- SC_OFF --><div class="md"><p>As CMake 4.0.0 and GCC-15 support, we could use cmake like this:</p> <p><code>cmakelists.txt</code>: ```cmake cmake_minimum_required(VERSION 4.0.0) set(CMAKE_CXX_STANDARD 23) set(CMAKE_EXPERIMENTAL_CXX_IMPORT_STD &quot;a9e1cf81-9932-4810-974b-6eccaf14e457&quot;)</p> <p>set(CMAKE_CXX_STANDARD_REQUIRED OFF) set(CMAKE_CXX_MODULE_STD 1)</p> <p>project(cpptest VERSION 0.1.0 LANGUAGES CXX)</p> <p>add_executable(cpptest main.cpp) ```</p> <p><code>main.cpp</code> <code>cpp import std; int main(){ std::println(&quot;Hello world!&quot;); } </code></p> <p>Wonderful.
